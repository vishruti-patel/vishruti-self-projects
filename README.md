## 📂 Projects Included

### 1️⃣ 🛡️ Data Quality Mini Framework
A **lightweight, config-driven data quality framework** that enforces data contracts, validates datasets, and prevents bad data from flowing into analytics or ML systems. Inspired by Great Expectations & Soda, but intentionally minimal, developer-friendly, and easy to integrate in CI/CD or pipelines.

**Highlights**
- YAML-based rules (schema, nulls, uniqueness, allowed values, ranges, freshness)
- JSON reporting + CLI summary
- PASS / FAIL status (CI friendly)
- Demonstrates real-world DE reliability mindset

### 2️⃣ 📊 SaaS Subscriptions SQL Analytics Project
A SQL-focused analytics project using a **SaaS subscription dataset** to derive insights like churn, revenue, user lifecycle behavior, retention, and business KPIs. Designed to show SQL problem-solving depth and analytical storytelling.

**Highlights**
- Business-driven scenario: subscriptions, plans, churn, upgrades, renewals
- Core analytics queries with commentary
- Clean SQL, structured thought process
- Resume & interview-friendly
